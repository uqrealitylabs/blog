# UQ Reality Labs blog

Project write-ups, event recaps, and experiments from the UQ Reality Labs
community.

## Contributing

Fork the repository and add a new markdown file to `_posts`. Follow the
frontmatter used by the existing posts, then open a pull request so the
executive team can review it.

Posts are served under `/blog`, matching the main site's link at
[uqrealitylabs.com/blog](https://uqrealitylabs.com/blog).

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

The site is built and deployed to GitHub Pages by
`.github/workflows/pages.yml`.
